# Bejuco pricing dashboard

Published automatically each day by the private
[`bejuco-market-data`](https://github.com/skiandwake/bejuco-market-data) repo. Nothing
here is edited by hand — a push overwrites it.

**Dashboard: https://skiandwake.github.io/bejuco-dashboard/**

Three files only:

| | |
|---|---|
| `index.html` | the rendered dashboard |
| `table.json` | the bucket metrics, read by the weekly pricing review |
| `changes.json` | the PriceLabs settings change ledger |

Reservation-level data — ids, ADR, revenue — is deliberately **not** published and stays
in the private repo.
